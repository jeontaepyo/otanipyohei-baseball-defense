- Android Chrome: 북마크 + 홈 화면에 추가/앱 설치 안내
- '제대로 배우기'를 12개 PART의 상세 수비 커리큘럼으로 확장
- 각 PART에 실제 경기 판단 기준, 핵심 체크, 팁 추가
- 9개 포지션 모두 '기본 수비 완전정리' 추가
- 각 포지션마다 준비/타구/커버/백업/상황별 역할, 많이 하는 실수, 경기 전 연습 항목 추가

오태니표헤이 수비 웹앱 v4.1

이번 수정
- 화살표 끝 삼각형을 더 작고 날렵하게 수정
- 2루↔3루 런다운 애니메이션 확대
- 3B → SS → P → 2B로 후속 수비수가 계속 앞자리를 채우는 회전 표시
- LF는 3루 뒤, CF는 2루 뒤의 깊은 백업으로 움직임 표시
- RF는 반대편/다른 주자를 지키며 모두 런다운 선에 몰려들지 않는 역할 표시

적용
1) simulator.js 교체
2) v4.js 교체
3) v4.css 교체
4) sw.js 교체
index.html은 v4와 동일하므로 그대로 두어도 됩니다.

적용 후 Cmd+Shift+R 강력 새로고침을 권장합니다.
